# Copia de seguridad de backgrounds JPEG

Esta carpeta conserva las 28 entregas JPEG creadas durante la integración responsive de Sprint 6.6.3 y la posterior
extensión del sistema modular de continuidad a las cinco colecciones.

- No es una fuente de assets de producción.
- Ningún archivo de `src/` debe referenciar estas copias.
- Las versiones activas se entregan en WebP desde `src/assets/themes/<theme-id>/backgrounds/`.
- Los PNG maestros generados se conservan fuera del bundle.

La copia inicial se creó el 2026-07-28 antes de retirar los JPEG de los directorios activos. El 2026-07-29 se añadieron
las copias de seguridad `*-body-*` de Royal, Boho, Dark, Magnolia y Linen. El tamaño agregado actual es 10.278.692
bytes.
