# Glossary

| Término               | Definición                                                                      |
|-----------------------|---------------------------------------------------------------------------------|
| Engine                | Núcleo que valida una definición, resuelve secciones y orquesta su renderizado. |
| Core                  | Contratos y mecanismos independientes del dominio y de proveedores externos.    |
| Invitation            | Instancia concreta de un evento expresada mediante configuración tipada.        |
| Invitation Definition | Contrato declarativo de metadatos, tema, secciones y capacidades.               |
| Section               | Bloque visible y ordenable de la experiencia.                                   |
| Feature               | Módulo funcional completo, como RSVP, galería o música.                         |
| Capability            | Configuración opcional que activa una feature y aporta sus parámetros.          |
| Theme                 | Identidad visual compuesta por tokens y variantes justificadas.                 |
| Design Token          | Decisión visual semántica y reutilizable.                                       |
| Repository            | Contrato de lectura o escritura usado por una feature.                          |
| Adapter               | Implementación concreta de un contrato, por ejemplo Supabase.                   |
| Event package         | Contenido y convenciones de un dominio, inicialmente wedding.                   |
| Admin                 | Interfaz opcional que consume respuestas; no forma parte del Core.              |
