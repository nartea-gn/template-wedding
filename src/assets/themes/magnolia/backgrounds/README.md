# BG-MAGNOLIA-001 — Magnolia watercolor background

## Estado y uso

`BG-MAGNOLIA-001` es la familia responsive activa para Landing, RSVP y el estado de éxito. Usa papel marfil rosado,
ramas finas de magnolia y eucalipto pálido con una presencia floral periférica y ligera. La apertura v2 reserva un
corredor central-superior estable para nombres y textos; Landing continúa después mediante un módulo de cuerpo ligero
con la ornamentación desplazada hacia los márgenes.

## Procedencia y prompt maestro

- Herramienta: generador de imágenes integrado de Codex.
- Fecha: 2026-07-28.
- Tipo: obra generada específicamente para Nartea; sin texto, logos ni recursos de terceros.

```text
Create a refined watercolor wedding website background for the Magnolia collection on warm blush-ivory paper.
Use slender magnolia branches with small dusty-pink and ivory flowers, pale eucalyptus leaves and restrained beige
washes anchored to the extreme outer corners and edges. Preserve a calm, uninterrupted central-upper reading corridor
of 65–70 percent for wedding names and introductory text. Adapt the composition deliberately for portrait mobile,
4:3 tablet and wide desktop. No oversized flowers in the title area, people, text, frames, UI, logos, watermark or
repeated wallpaper.
```

## Reglas

- Las flores no deben competir con nombres, countdown ni campos.
- Las tres aperturas v2 sustituyen las composiciones con flores que invadían la zona superior de lectura.
- Landing funde la apertura con el módulo de cuerpo; RSVP conserva una presencia periférica tenue.
