# BG-LINEN-001 — Linen botanical background

## Estado y uso

`BG-LINEN-001` es la familia responsive activa para Landing, RSVP y el estado de éxito. Trabaja con lino color avena,
ramas de olivo, semillas secas y pinceladas piedra de ornamentación mínima. Landing continúa sobre un módulo repetible
de lino, mineral y botánica contenida.

## Procedencia y prompt maestro

- Herramienta: generador de imágenes integrado de Codex.
- Fecha: 2026-07-28.
- Tipo: obra generada específicamente para Nartea; sin texto, logos ni recursos de terceros.

```text
Create a quiet premium editorial wedding website background for the Linen collection on tactile oatmeal linen paper.
Use sparse olive branches, dry seed stems, warm stone brush marks and muted grey-green ink only around the perimeter.
Preserve a very large clean center and a restrained lower-right closing branch. No people, text, flowers, frames, UI,
logos, watermark, harsh contrast or repeated wallpaper.
```

## Reglas

- La textura debe sentirse material, nunca como ruido digital.
- La ornamentación será la más contenida de las cinco colecciones.
- Landing funde la apertura con el módulo de cuerpo; el fondo base sigue siendo suficiente si el bitmap no carga.
