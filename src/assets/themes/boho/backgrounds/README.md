# BG-BOHO-001 — Boho botanical background

## Estado y uso

`BG-BOHO-001` es la familia responsive activa para Landing, RSVP y el estado de éxito. Combina papel artesanal cálido,
botánica oliva, terracota y un sol ocre, manteniendo una zona editorial central amplia. Landing conserva la apertura
original y continúa sobre un módulo de cuerpo repetible de la misma familia.

Use restrained olive and sage botanicals, dry grasses, subtle terracotta accents and one soft ochre sun.
