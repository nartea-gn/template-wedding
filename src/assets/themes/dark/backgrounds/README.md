# BG-DARK-001 — Dark celestial background

## Estado y uso

`BG-DARK-001` es la familia responsive activa para Landing, RSVP y el estado de éxito. Construye una atmósfera azul
medianoche con nubes de tinta, luna y detalles champagne muy contenidos. Landing continúa sobre un módulo nocturno
repetible sin duplicar la luna.

## Procedencia y prompt maestro

- Herramienta: generador de imágenes integrado de Codex.
- Fecha: 2026-07-28.
- Tipo: obra generada específicamente para Nartea; sin texto, logos ni recursos de terceros.

```text
Create a premium editorial wedding website background for the Dark collection on deep midnight-blue mineral paper.
Use subtle ink clouds, one quiet moon, sparse champagne-gold constellations and restrained luminous dust around the
perimeter. Preserve a broad low-contrast center for readable content and a minimal lower-edge closing gesture.
No people, text, frames, UI, logos, watermark, neon effects or repeated wallpaper.
```

## Reglas

- Utilizar `screen` para conservar luz y profundidad sin ensuciar los negros.
- Mantener los destellos fuera de la columna de contenido.
- Landing funde la apertura con el módulo de cuerpo; RSVP reduce la intensidad de la apertura.
